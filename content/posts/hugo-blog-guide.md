## 为什么选择Hugo？

Hugo 是一个用 Go 语言编写的静态网站生成器，速度极快构建只需几秒。

## 主要优势

1. **构建速度快** - 比 Jekyll 快 10-100 倍
2. **无需依赖** - 编译成单个可执行文件
3. **主题丰富** - 数百个精美主题可选
4. **GitHub 原生支持** - GitHub Actions 自动部署

## 快速部署步骤

1. 创建 Hugo 项目
2. 推送到 GitHub
3. 配置 GitHub Actions
4. 开启 GitHub Pages

开始你的博客之旅吧！
