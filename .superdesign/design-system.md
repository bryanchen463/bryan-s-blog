# Bryan Chen's Blog — Five Elements Design System

## Product Context
Personal tech & life blog built with Hugo + GitHub Pages. Target audience: Chinese tech community, readers interested in development tools, DevOps, and productivity. Goal: distinctive, warm, and alive design that stands out from generic cold-white tech blogs.

---

## Visual Direction — 五行设计哲学

**Core philosophy:** 金为骨，木为势，火为神，水为流，土受制

### Five Elements Color Palette

**甲木 Wood (Structure & Growth)**
- Primary: `#1a5c54` (deep forest teal — titles, main headings)
- Secondary: `#2a7a6e` (h2 headings)
- Tertiary: `#4db89e` (decorative, active states)
- Usage: h1/h2 titles, vertical guide lines, structural elements

**丁火 Fire (Focus & Energy)**
- Primary: `#c84b31` (cinnabar red — CTA buttons)
- Secondary: `#d4622a` (warm orange — hover states)
- Tertiary: `#e07540` (accent highlights)
- Usage: main buttons, important links, focus indicators

**壬/癸水 Water (Flow & Breath)**
- Background: `#e8f0f3` (pale water teal — main background)
- Card BG: `rgba(255, 255, 255, 0.72)` (frosted glass cards)
- Border: `rgba(56, 133, 127, 0.15)`
- Subtle gradients for flow atmosphere
- Usage: page background, card layers, transitions

**金 Gold (Precision & Order)**
- Text: `#2c3e3a` (charcoal — body text)
- Code blocks: dark accent with teal border
- Usage: typography precision, borders, layout boundaries

**土 Earth (Controlled Support)**
- Header: frosted glass, minimal
- Footer: light, airy, transparent
- Rule: Earth can support but must not weigh down

---

## Typography

- **Headings:** System font stack, bold weight, tight tracking
- **Body:** 1.05-1.08em, line-height 1.85-1.9
- **Code:** Monospace, dark background

---

## Spacing System

- Container max-width: 1200px
- Content padding: 2-2.5rem horizontal
- Section spacing: 2-3rem vertical
- Card padding: 1.8-2rem

---

## Dark Mode

Same color logic but darker values:
- Background: `#0d1a1e`
- Cards: `rgba(20, 40, 46, 0.80)`
- Wood accent: `#4db89e` (brighter for dark bg)
- Fire accent: `#e07540` (warmer)

---

## Key Design Rules

1. Background must NOT be flat white — always subtle gradient + atmosphere
2. Cards are frosted glass with teal border, not flat white boxes
3. Headings must have 甲木 green character — not just dark gray
4. Fire 丁火 is used ONLY on buttons and critical highlights — never scattered
5. Page must breathe — generous whitespace, no content jamming
